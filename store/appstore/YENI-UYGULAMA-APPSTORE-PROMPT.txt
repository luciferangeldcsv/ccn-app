   - Promotional Text, Description, Keywords (≤100), Support URL, Copyright, Build seç, App Review notu + örnek dosya.
   - "Automatically release this version" seçili kalsın.
5) App Information: Category'de ÜSTTEKİ kutu (Primary) seçilmeli; Subtitle (≤30); Age Ratings anketi (hepsine None/No → 4+); Content Rights.

   (Bu bölümü yalnızca ben yapabilirim; API ile doldurulamıyor.)
8) Add for Review → Submit. İnceleme genelde 24-48 saat.
